# 🔤 Fonts

Oh My PoshやCLIのアイコンを表示するには、[Nerd Fonts](https://www.nerdfonts.com/)対応フォントが必要となる。

WSL 2でWindows側のターミナルやエディタを使用する場合は、フォントをWindowsにインストールし、使用するターミナルとエディタの両方でフォントを設定する。


## 📝 Recommended Fonts

Nerd Fonts対応の日本語プログラミングフォントとして、以下を推奨する。

いずれも[yuru7](https://github.com/yuru7)氏が開発・公開している、日本語フォントとプログラミング向け欧文フォントを組み合わせたNerd Fonts対応フォントである。

| フォント | 構成 | 特徴 |
| --- | --- | --- |
| [HackGen35 Console NF](https://github.com/yuru7/HackGen) | 日本語：源柔ゴシック / 英数字：Hack | 丸みのある日本語と落ち着いた英数字で、柔らかく読みやすい |
| [UDEV Gothic 35NF](https://github.com/yuru7/udev-gothic) | 日本語：BIZ UDゴシック / 英数字：JetBrains Mono | UDフォント由来の高い判読性を重視し、日本語・英数字とも識別しやすい |
| [PlemolJP35 Console NF](https://github.com/yuru7/PlemolJP) | 日本語：IBM Plex Sans JP / 英数字：IBM Plex Mono | IBM Plexで統一された、モダンで端正なデザインと豊富なウェイトが特徴 |


## 🪟 Installation

使用するフォントのGitHub ReleasesからNerd Fonts対応版をダウンロードする。

ダウンロードしたフォントをWindowsへインストールする。

インストール後、使用するターミナルとエディタでフォントを設定する。

Windows側の設定例については[Windows設定ガイド](windows.md)を参照する。
