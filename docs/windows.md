# 🪟 Windows Configuration

WSL 2と組み合わせて使用するWindows側のアプリケーション設定について説明する。

これらの設定はGNU Stowによる自動反映の対象ではない。


## 📝 Fonts

Windows TerminalやVS CodeでOh My PoshやCLIのアイコンを正しく表示するには、Nerd Fonts対応フォントを設定する。

フォントの導入については[フォントガイド](fonts.md)を参照する。


## 💻 Windows Terminal

設定例はrepository内の[Windows Terminal設定](../windows/windows-terminal/settings.json)を参照する。

使用するプロファイルのフォントには、WindowsへインストールしたNerd Fonts対応フォントを設定する。


## 🧑‍💻 Visual Studio Code

設定例はrepository内の[Visual Studio Code設定](../windows/vscode/settings.json)を参照する。

エディタと統合ターミナルには、WindowsへインストールしたNerd Fonts対応フォントを設定する。


## 🐚 PowerShell

設定例はrepository内の[PowerShell設定](../windows/powershell/Microsoft.PowerShell_profile.ps1)を参照する。

Windows側のPowerShell設定として必要に応じて適用する。
